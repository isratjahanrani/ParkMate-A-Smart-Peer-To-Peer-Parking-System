## 🌆 Overview & Urban Mobility Challenges

In dense urban metropolitan areas like Dhaka, over **30% of inner-city traffic congestion** is generated by drivers cruising in search of vacant parking spaces. Simultaneously, hundreds of private residential driveways, commercial basements, and vacant parking bays remain completely empty during off-peak and working hours.

### The ParkMate Solution
ParkMate transforms urban parking into a shared-economy platform:
- **For Drivers:** Real-time discovery, transparent hourly pricing in Bangladeshi Taka (BDT), turn-by-turn GPS navigation, guaranteed reservations, and instant cashless mobile checkout.
- **For Hosts (Space Owners):** Turn unused parking slots into recurring passive income with complete control over availability schedules, vehicle-type pricing, and automated payout withdrawals.
- **For Cities:** Reduces traffic congestion, lowers vehicular carbon emissions from idle cruising, and optimizes existing spatial infrastructure without costly civil construction.

## 🚀 Key Features & Role-Based Personas

### 1. Driver Experience (Seekers)
- 🔍 **Smart Search Engine:** Filter parking spots by vehicle category (Car, Motorcycle, Truck, SUV), distance radius, hourly price range, and amenities (CCTV, Covered Parking, EV Charging, Security Guard).
- ⏱️ **Real-Time Live Availability:** Dynamic spot occupancy indicators updated via simulated live feeds and Supabase subscriptions.
- 🗺️ **Interactive Map & GPS Navigation:** Map-based spot discovery with calculated travel distance, estimated arrival times (ETA), and turn-by-turn route visualization.
- 📅 **Dual Reservation Modes:**
  - **Book Now:** Instant on-demand parking spot reservation for immediate parking.
  - **Reserve Later:** Pre-scheduled reservations with customizable start and end timestamps.
- 💳 **Cashless Digital Payments:** Integrated checkout supporting **bKash**, **Nagad**, **Rocket**, and traditional debit/credit cards.
- ⭐ **Ratings & Reviews:** Verified tenant reviews and star ratings ensuring accountability and trust.

### 2. Host Experience (Space Owners)
- 🏡 **Multi-Spot Inventory Management:** Effortlessly register single spots or multi-bay parking facilities with detailed addresses, GPS pinpoints, spot photos, and access instructions.
- 🏷️ **Dynamic Tiered Pricing:** Configure hourly, daily, and monthly rates tailored to vehicle classifications (e.g., standard rates for bikes, premium rates for heavy commercial vehicles).
- 📋 **Booking Control Center:** Review, approve, or decline reservation requests with real-time incoming booking notifications.
- 📈 **Earnings & Occupancy Analytics:** Interactive charts powered by **Recharts** displaying daily/weekly revenue, utilization rates, and peak parking hours.
- 💸 **Direct Payout Withdrawals:** Automated balance calculation with one-click withdrawal requests directly to bKash or Nagad mobile wallets.

### 3. Administrator & Governance Suite
- 🛡️ **Host & Property Verification:** Review host identity documentation, ownership deeds, and photo audits before granting verified badges.
- ⚖️ **Dispute Resolution Pipeline:** Mediate conflicts between hosts and drivers (e.g., overstay disputes, unauthorized vehicles, refund appeals).
- 📊 **Platform Health & Metrics:** Track active users, total completed bookings, platform commission revenue, and system uptime.
- 🔒 **Security & Access Enforcement:** Role-based access control (RBAC) ensuring strict separation between driver, host, and admin operational scopes.

## 🗄️ Database & Spatial Architecture (Supabase + PostGIS)

The backend database leverages PostgreSQL with the **PostGIS** geospatial extension to calculate high-speed geographic proximity queries:

```sql
-- Core PostgreSQL Tables
├── users                 -- Authentication & role definitions (driver, host, admin)
├── user_profiles         -- Full name, phone, verified badges, host business details
├── vehicles              -- Registered user vehicles (license plates, models, vehicle types)
├── parking_spots         -- Spot title, location (geography Point), address, amenities
├── pricing_rules         -- Tiered vehicle hourly / daily / monthly rate tables
├── bookings              -- Reservation records, timestamps, total price, status
├── reviews               -- Driver feedback, ratings (1 to 5 stars), comments
├── payments              -- Payment method (bKash/Nagad/Card), transaction IDs, status
├── payouts               -- Host earnings withdrawal requests and transfer logs
└── disputes              -- Conflict tickets, resolution timestamps, admin mediation notes
```

### Security & Row-Level Security (RLS)
All tables enforce PostgreSQL **Row-Level Security (RLS)**:
- Users can only read and modify their own vehicles, payment records, and private profiles.
- Parking spot listings are publicly queryable, but only verified owners can update spot metadata or pricing.
- Administrators possess elevated audit policies for system monitoring and dispute resolution.

## 🚀 Getting Started & Local Installation

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm** or **yarn**
- **Supabase Account** (or a local PostgreSQL database with PostGIS enabled)

---

### Step 1: Clone Repository
```bash
git clone https://github.com/isratjahanrani/ParkMate-A-Smart-Peer-To-Peer-Parking-System.git
cd ParkMate-A-Smart-Peer-To-Peer-Parking-System
```

---

### Step 2: Install Dependencies
```bash
npm install
```

---

### Step 3: Configure Environment Variables
Copy the template configuration file:
```bash
cp .env.example .env
```
Open `.env` and provide your Supabase project credentials:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

---

### Step 4: Database Setup (Supabase)
1. Navigate to your [Supabase Dashboard](https://supabase.com).
2. Open the **SQL Editor** tab.
3. Copy the entire contents of [`supabase_schema.sql`](supabase_schema.sql) and run it.
4. This will enable `postgis`, create all 10 tables, and configure Row-Level Security policies.

---

### Step 5: Launch Development Server
```bash
npm run dev
```
Open your browser and navigate to: **[http://localhost:5173](http://localhost:5173)**

---

### Step 6: Build for Production
To generate optimized production bundles:
```bash
npm run build
```
